# Data

The dataset is **not included** in this repository. Download it yourself and place it here:

```
data/
├── README.md
├── survey.csv            <- download this (raw survey, 1,259 rows x 27 columns)
└── cleaned_survey.csv    <- generated by notebooks/02_preprocessing.ipynb
```

- **Source:** [Mental Health in Tech Survey](https://www.kaggle.com/datasets/osmi/mental-health-in-tech-survey) by Open Sourcing Mental Illness (OSMI), 2014 survey, published on Kaggle.
- **License:** CC BY-SA 4.0 (see the Kaggle page).
- **File expected by the code:** `data/survey.csv` (notebooks 01 and 02 read `../data/survey.csv` relative to `notebooks/`).

The responses are anonymous, but they concern mental health, which is sensitive. Do not commit the raw or cleaned CSV files; `.gitignore` already excludes `*.csv`.
